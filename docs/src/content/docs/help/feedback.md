## From your phone

In Atlas, select **Send feedback**, then **Report a bug** or **Suggest an idea**. Atlas opens your email app with a message ready to fill in. A bug report already includes your Atlas version, phone and Android version.

You do not need a GitHub account.

## On GitHub

[Open an issue on GitHub](https://github.com/juleshall4/atlas/issues/new/choose) and select a template:

- **Bug** for something that does not work properly
- **Feature** for a new feature or a change

Search the [existing issues](https://github.com/juleshall4/atlas/issues) first, in case someone has already reported it.
