title: Problems
description: Fixes for common problems with the keyboard.
---

## The keyboard does not work properly

Open **Keyboard** in Atlas. If you see **Finish setup**, select it and do the steps that are not done.

## Sym does not show emoji

In the phone's Settings, open **Shortcut keys** and set **Sym key** to **Programmable key**.

## Swiping does not work in one app

In the phone's Settings, open **Scroll assistant** and find the app. Set it to **Sliding Mode 1**.

## Something else is wrong

[Send feedback](/help/feedback/) and say what happened.
