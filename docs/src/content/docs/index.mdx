Atlas adds swipe typing, keyboard shortcuts and better speaker sound to the Unihertz Titan 2 Elite. Each feature works on its own, so you can turn on only the ones you want.

## Check your phone

You need:

- a Unihertz Titan 2 Elite
- Android 14 or later

## Install Atlas

Install Atlas with Obtainium so you get each update automatically.

1. Install [Obtainium from GitHub](https://github.com/ImranR98/Obtainium/releases).
2. In Obtainium, touch **Add App**.
3. Paste this address as the app source, then touch **Add**:

   ```text
   https://github.com/juleshall4/atlas
   ```

4. Touch **Install**.

You can also [download the latest Atlas APK from GitHub](https://github.com/juleshall4/atlas/releases/latest) and install it yourself. You'll need to install each update the same way.

## Set up the keyboard

Open Atlas and select **Keyboard**. If you see **Finish setup**, select it. Atlas shows only the steps that are not done yet.

1. **Enable Atlas** adds Atlas to your list of keyboards.
2. **Choose Atlas** makes it the keyboard you type with.
3. **Allow overlay** lets Atlas read touches on the keys. Atlas never reads the screen.
4. **Turn on Scroll assistant** lets you swipe on the keys in every app.
5. **Turn on Atlas in Accessibility** lets Quick open start apps, and keeps notifications from catching your swipes.

You can use the rest of Atlas before you finish these steps.

## Turn on more features

Shortcuts and Audio are off at the start. Turn on the ones you want:

- [Quick open and actions](/keyboard/shortcuts/) in **Shortcuts**
- [Better media](/audio/speaker/) and [Clearer calls](/audio/calls/) in **Audio**

## Your privacy

All your data stays on your phone. Nobody, including the developer, can see it.

Atlas does not learn words from password, email, web address or private fields.
