Atlas makes the Titan 2 Elite's physical keyboard do more. Type whole words by sliding your finger across the keys, open apps and edit text from the keys, and get better sound from the speaker.

Each feature is separate. Turn on the ones you want and leave the rest off.

## What you need

- a Unihertz Titan 2 Elite
- Android 14 or later

## Install Atlas

The easiest way to install Atlas is with Obtainium, a free app that installs apps from GitHub and keeps them up to date.

1. Install [Obtainium from GitHub](https://github.com/ImranR98/Obtainium/releases).
2. Open Obtainium and touch **Add App**.
3. Paste this address as the app source, then touch **Add**:

   ```text
   https://github.com/juleshall4/atlas
   ```

4. Touch **Install**.

Obtainium tells you when a new version of Atlas is ready.

If you prefer, you can [download the Atlas APK from GitHub](https://github.com/juleshall4/atlas/releases/latest) and install it yourself. You'll need to do this again for each update.

## Set up the keyboard

The keyboard features need a few Android permissions. Open Atlas, select **Keyboard**, then select **Finish setup**. Atlas lists only the steps you have not done yet, and takes you to the right Android page for each one.

| Step | Why Atlas needs it |
|---|---|
| Enable Atlas | Adds Atlas to the keyboards Android can use. |
| Choose Atlas | Makes Atlas the keyboard you type with. |
| Allow overlay | Lets Atlas feel your finger on the keys, so you can swipe. Atlas never reads what is on the screen. |
| Turn on Scroll assistant | Lets swipes on the keys reach Atlas in every app. |
| Turn on Atlas in Accessibility | Lets Quick open start apps, and stops notifications from catching your swipes. |

You can use the rest of Atlas while you do these steps. When they are all done, **Finish setup** goes away.

## Choose what to turn on

Swipe typing and the typing features are ready after setup. These are off until you turn them on:

- [Quick open](/keyboard/shortcuts/#open-apps-with-quick-open), to open apps from the keys
- [Actions](/keyboard/shortcuts/#edit-text-with-actions) such as undo and copy (Delete a word is already on)
- [Better media](/audio/speaker/), for fuller speaker sound
- [Clearer calls](/audio/calls/), for clearer voices in app calls
- [Keyboard light](/keyboard/keys/#light-up-the-keys), which lights the keys when you touch them

## Your privacy

Everything Atlas learns stays on your phone. Atlas does not connect to the internet, and nobody else, including the developer, can see your data.

Atlas never learns words from password, email, web address or private fields.
