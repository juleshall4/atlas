## Open apps with Quick open

Quick open lets you open an app from anywhere with two keys. Give the app a letter, then hold Fn and press that letter.

You can also press Fn and let go, then press the letter within 1 second. This is easier with one hand.

### Turn on Quick open

Open **Shortcuts** and turn on **Quick open**. If you see **Finish setup**, select it first: Quick open needs Atlas turned on in Accessibility so it can start apps.

<Setting path={['Shortcuts']} name="Quick open" on />

### Give an app a letter

1. In **Shortcuts**, select **Apps**.
2. Touch the app.
3. Press the letter you want.

Each letter can open one app. To move a letter to a different app, first touch the app that has it and press Backspace to remove it.

Apps open with the normal Android animation. To open them instantly, turn off **Animation** in **Shortcuts**.

## Edit text with actions

Hold Alt and press a key to edit text without touching the screen:

| Keys | Action |
|---|---|
| Alt and Z | Undo |
| Alt and Y | Redo |
| Alt and A | Select all |
| Alt and C | Copy |
| Alt and X | Cut |
| Alt and V | Paste |
| Alt and Backspace | Delete a word |

Only Delete a word is on at the start, so Alt and a letter still type symbols. To turn on the actions you want, open **Shortcuts** and select **Keys**.

When an action is off, Alt and that key type a symbol as normal. Actions need Atlas to be your keyboard.
