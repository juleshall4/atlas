## Open apps with Quick open

Give an app a letter, then hold Fn and press that letter to open the app from anywhere. With one hand, you can press Fn and let go, then press the letter within 1 second.

### Turn on Quick open

Open **Shortcuts** and turn on **Quick open**. If you see **Finish setup**, select it first: Quick open needs Atlas turned on in Accessibility so it can start apps.

<Setting path={['Shortcuts']} name="Quick open" on />

### Give an app a letter

1. In **Shortcuts**, select **Apps**.
2. Touch the app.
3. Press the letter you want.

Each letter opens one app. To move a letter, touch the app that has it and press Backspace, then give it to the other app.

To open apps without the Android animation, turn off **Animation** in **Shortcuts**.

## Edit text with actions

Hold Alt and press a key to edit text without touching the screen:

| Keys | Action |
|---|---|
| Alt and Z | Undo |
| Alt and Y | Redo |
| Alt and A | Select all |
| Alt and C | Copy |
| Alt and X | Cut |
| Alt and V | Paste |
| Alt and Backspace | Delete a word |

Only Delete a word is on at the start. When an action is off, Alt and that key type a symbol. To turn on actions, open **Shortcuts** and select **Keys**. Actions need Atlas to be your keyboard.
