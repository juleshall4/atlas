title: Languages
description: Atlas can suggest and correct words in other languages. Download a language, then add it in Atlas.
---

Atlas does not connect to the internet, so you download a language file and add it yourself.

## Add a language

1. On your phone, download a language from the [Downloads](/atlas/downloads/#languages) page.
2. In Atlas, open **Keyboard** and select **Language**.
3. Select **Add a downloaded language**, then choose the file you downloaded.

Atlas then uses the language. To switch back, select **English (British)** or **English (American)** on the same page.

## What works in other languages

In a downloaded language, Atlas:

- suggests words as you type, including words with accents when you type them without
- corrects spelling mistakes
- learns the words you type that are not in its list

Swipe typing stays in English. Suggestions for the next word, before you type any letters, work best in English.
