## Clearer calls

Clearer calls makes voices easier to hear when you use the speaker in WhatsApp and other apps that call over the internet. Normal phone calls sound the same as before.

## Give Atlas permission

To know when an app call starts, Atlas needs a permission that Android only lets you give from a computer. You only need to do this once.

1. Turn on USB debugging on your phone, and install `adb` on your computer.
2. Connect your phone to the computer with a USB cable.
3. On the computer, run this command:

   ```sh
   adb shell pm grant com.atlas android.permission.DUMP
   ```

Atlas shows the same command in **Audio**, with a button to copy it.

Atlas uses this permission only to check whether an app call is active.

### Use an AI agent instead

If you use an AI agent that can run commands on your computer, such as Claude Code or Codex, connect your phone with a USB cable and give the agent this prompt:

```text
My Android phone is connected to this computer with a USB cable. Help me give the Atlas app a permission over adb.

1. Check that adb is installed. If it is not, install Android platform tools for my operating system.
2. Run adb devices. If my phone is not listed, or shows as unauthorized, tell me how to turn on USB debugging and allow this computer on the phone. Then wait for me.
3. Run this command: adb shell pm grant com.atlas android.permission.DUMP
4. Tell me if it worked.

Do not run any other commands on my phone.
```

## Turn on Clearer calls

After you run the command, open **Audio** and turn on **Clearer calls**.
