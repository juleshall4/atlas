## From Atlas

In Atlas, select **Send feedback**, then **Report a bug** or **Suggest an idea**. Atlas opens your email app with a message ready to fill in.

A bug report already includes your Atlas version, phone model and Android version, so you only need to say what happened. You do not need a GitHub account.

## On GitHub

If you have a GitHub account, you can [open an issue on GitHub](https://github.com/juleshall4/atlas/issues/new/choose). Choose **Bug** for something that does not work, or **Feature** for an idea.

Search the [existing issues](https://github.com/juleshall4/atlas/issues) first, in case someone has already reported it.
